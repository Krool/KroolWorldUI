# Screenshots for the mod page

Drop PNGs here with these names, then add them to the matching section of the root README with an
absolute URL (`https://raw.githubusercontent.com/Krool/KroolWorldUI/main/docs/screenshots/<name>.png`).
Thunderstore cannot load relative image paths.

Take them in the KroolDev profile at 1920x1080 with the default settings. Steam's F12 saves to
`Steam\userdata\<id>\760\remote\892970\screenshots`. Crop to the element plus a little of the HUD
around it so the image reads at the page's width.
