# Screenshots for the mod page

The root README embeds these with absolute URLs
(`https://raw.githubusercontent.com/Krool/KroolWorldUI/main/docs/screenshots/<name>`); Thunderstore
cannot load relative image paths.

Source captures stay on the owner's machine, never in the repo: Steam F12 screenshots in
`Steam\userdata\35340931\760\remote\892970\screenshots`, Game Bar recordings in `Videos\Captures`.
Stills are ffmpeg crops of those screenshots; GIFs are cut from the recordings (crop, 12-20 fps,
128-color palette, about 1.5 MB each). Find moments by tiling one frame every few seconds into contact
sheets.
